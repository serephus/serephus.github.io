0899 - Orderly Queue

2026-10-09·#Math·#String·#Sorting·#Lexicographically Minimal String Rotation·#Hard

Description (leetcode)

You are given a string s and an integer k. You can choose one of the first k letters of s and append it at the end of the string.

Return the lexicographically smallest string you could have after applying the mentioned step any number of moves.

Example 1:

Input: s = “cba”, k = 1

Output: “acb”

Explanation:

In the first move, we move the 1st character ‘c’ to the end, obtaining the string “bac”.

In the second move, we move the 1st character ‘b’ to the end, obtaining the final result “acb”.

Example 2:

Input: s = “baaca”, k = 3

Output: “aaabc”

Explanation:

In the first move, we move the 1st character ‘b’ to the end, obtaining the string “aacab”.

In the second move, we move the 3rd character ‘c’ to the end, obtaining the final result “aaabc”.

Constraints:

  • 1 <= k <= s.length <= 1000
  • s consist of lowercase English letters.

impl Solution {
    pub fn orderly_queue(s: String, k: i32) -> String {
        // there are only 2 cases
        // when k == 1, we can only rotate the string and took the minimal
        // when k > 1, we effectively sort the string, why? I'm too lazy to copy explanation
        if k > 1 {
            let mut v: Vec<_> = s.chars().collect();
            v.sort_unstable();
            return v.into_iter().collect();
        }
        (0..s.len())
            .map(|i| s[i..].to_owned() + &s[..i])
            .min()
            .unwrap_or_default()
    }
}
